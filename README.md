### 🚀 Deploy to Render

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/etiasprotech/bot)

**Manual Deploy:**
1. Fork this repo
2. Go to [dashboard.render.com](https://dashboard.render.com)
3. New Web Service -> Connect your fork
4. Build: `npm install`
5. Start: `npm start`
6. Add ENV: `SESSION_ID` = your session

### 📲 Pair Code
Get session from: `https://etias-pair.onrender.com`
